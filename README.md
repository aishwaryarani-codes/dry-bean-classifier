## a. Problem statement

Dry bean varieties have similar visual characteristics. This project compares five supervised classification methods that predict a bean's variety from numerical measurements extracted from its image: Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Support Vector Machine.

## b. Dataset description

- **Source:** [UCI Machine Learning Repository, Dry Bean, dataset ID 602](https://archive.ics.uci.edu/dataset/602/dry%2Bbean)
- **Instances:** 13,611
- **Input features:** 16 numerical measurements
- **Target:** `Class`, with seven varieties: Seker, Barbunya, Bombay, Cali, Dermosan, Horoz, and Sira
- **Missing values:** None according to UCI
- **License:** CC BY 4.0; dataset DOI: [10.24432/C50S4B](https://doi.org/10.24432/C50S4B)

The measurements were obtained from images of dry beans using a computer vision process. This project uses the tabular measurements, not the original images.

## c. GitHub Repository Link

**GitHub repository:** https://github.com/aishwaryarani-codes/dry-bean-classifier

The project contains `train.py` for data loading and model training, `metrics.py` for shared evaluation code, `charts.py` for result visualizations, `theme.py` and `assets/` for interface styling, `app.py` for the Streamlit interface, `requirements.txt`, `test_data.csv`, saved pipelines in `model/`, and experiment outputs in `results/`.

## d. Models used

The 13,611 rows are split once into 10,888 training rows and 2,723 test rows using a stratified 80/20 split (`random_state=42`). The test data is held aside during fitting. StandardScaler is fitted within pipelines for Logistic Regression, KNN, and SVM. All reported metrics use the same held-out rows. Precision, recall, and F1 are macro averages; multiclass AUC is one-vs-rest macro using predicted probabilities; MCC is the multiclass Matthews correlation coefficient.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Strong linear baseline: 0.9207 accuracy and 0.9042 MCC, with high macro F1 (0.9329). It is close to the top model while remaining relatively simple. |
| Decision Tree | Lowest accuracy (0.8884) and macro F1 (0.9036) among the five. It is easier to interpret, while the distance-based KNN and nonlinear SVM performed better on this split. |
| K-Nearest Neighbors | Second-highest accuracy (0.9166) and macro F1 (0.9292). Scaling helps distance-based comparisons; performance is strong but slightly below the SVM on this split. |
| Gaussian Naive Bayes | Lowest accuracy (0.7639), macro F1 (0.7677), and MCC (0.7154). Its independence and distribution assumptions appear less suitable for these measurements. |
| Support Vector Machine | Highest accuracy (0.9229), macro precision (0.9360), macro recall (0.9340), macro F1 (0.9350), and MCC (0.9067); AUC is tied with Logistic Regression at 0.9948. |
| **Overall winner** | Support Vector Machine on this held-out split; it leads on five of the six reported measures and ties AUC. |

## e. Streamlit app

**Local app:** http://localhost:8501  
**Live app:** [Add your deployed Streamlit Community Cloud URL]

The app lets a user upload a labeled CSV, compare all five saved models on the same rows, select a model, and inspect accuracy, AUC, macro precision/recall/F1, MCC, a confusion matrix, and a per-class report. It loads saved models and does not retrain on uploaded data. The input file must contain all 16 feature columns and the `Class` target column.

## Run locally

1. Create and activate a Python environment (Python 3.10 or newer recommended).
2. Install dependencies: `pip install -r requirements.txt`.
3. Train models and create the held-out test data: `python train.py`.
4. Start the interface: `streamlit run app.py`.

By default, `train.py` fetches UCI dataset 602 via `ucimlrepo`. To use a local CSV instead, run `python train.py --data-csv path/to/dry_bean.csv`; that CSV must include the `Class` target column. The training run writes five model files, `model/model_info.json`, `test_data.csv`, metrics, confusion matrices, and per-class reports.
